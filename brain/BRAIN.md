# Net2Map -- Project Brain

Net2Map is a web application that discovers and visualizes switch topologies via SNMP
(vendor-aware scanners, network map, rack view, endpoint tracking). It is a personal
homelab/network tool: the primary value is running Patric's own network reliably.

Reading order:

1. `brain/Goals.md` -- the few outcomes that matter this stretch.
2. `brain/roadmap.md` -- the live pipeline board.
3. `brain/Decisions.md` -- decisions with rationale.
4. `brain/How We Work.md` -- build rhythm and verification commands.

Key links: `README.md` (product overview, quickstart), `VERSION.md` (release history),
`BACKUP.md` (DB backup/restore), `docs/README.md` (doc map).

Naming: the product is "Net2Map" since v3.0.0 (formerly "NetMap", earlier
"Switch-Map"); identifiers use `net2map`. The GitHub repo is `netmap` until renamed to
`net2map`; the local folder is `switch-map`. See `brain/Decisions.md`, "Rebranding to
Net2Map".
